TASKLY CODES

Support

Taskly Codes helps you find equipment error codes locally and review a cautious AI-powered safety classification when AI Assistant is available.

Find an error code

  1. Open Search and enter the code, brand, category, or a short description of the problem.
  2. Choose the matching result to see its meaning, possible causes, checks, and safety notice.
  3. Use Favorites or History to find codes again. Your favorites, history, and notes are stored on your device.

Use AI Assistant

Select a category and symptom, add a short description, then submit the request. AI Assistant needs an internet connection and a configured service; it may be unavailable in some builds. It returns a high-level safety classification, not a guaranteed diagnosis or repair procedure. Do not enter passwords, payment details, or information that is not needed to describe the equipment problem.

Common problems

  • No code appears: try the exact code without extra spaces, then search by brand or symptom. The current catalogue is limited to the codes included in this version.
  • AI Assistant does not respond: check your connection, confirm the request contains a category and symptom, and try again later. A missing or invalid AI configuration cannot be fixed from inside the app.
  • Favorites, history, or notes are missing: check that you are using the same device and app installation. This data is local and is not synchronized to an account.
  • App opens the wrong page: update to the latest available version and restart the app.

What to include in a support request

Email iurigutu@gmail.com and include the app version, device model, operating-system version, language, the exact error code or AI screen involved, what you expected, what happened, and steps to reproduce it. Screenshots are helpful; remove names, addresses, serial numbers, or other sensitive information first.
